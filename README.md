# Dolphin Aquarium 🐬

Premium aquarium web application and catalog for Dolphin Aquarium, Madipakkam, Chennai. Featuring real-time catalog browsing, category filtering, detailed care guides, and WhatsApp direct ordering.

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## 🛠️ Tech Stack
- **Frontend**: React 19, Vite, Lucide Icons
- **Database & Auth**: Supabase (PostgreSQL, Supabase Auth, Storage)
- **Styling**: Vanilla CSS with dark ocean theme & glassmorphic design
